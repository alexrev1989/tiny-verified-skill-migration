# Submission packages

## arXiv

`arxiv/` contains the signed author source, bibliography, compiled bibliography, and concise upload instructions. The package is isolated from experiment traces, Git history, reviewer notes, credentials, and local paths.

## ICLR anonymous manuscript

`ICLR_anonymous/` preserves the final anonymous package from the publication archive. Text and PDF checks found no occurrence of `Alexander`, `Revyakin`, GitHub URLs, or ORCID identifiers in the anonymous paper.

Before any ICLR 2027 upload, port the source to the official conference style, verify the current main-text page limit, and repeat the double-blind audit. Do not add the public author repository URL to the anonymous manuscript during review.

The scientific results, evaluation thresholds, prompts, and models are frozen and must not be changed as part of submission preparation.
