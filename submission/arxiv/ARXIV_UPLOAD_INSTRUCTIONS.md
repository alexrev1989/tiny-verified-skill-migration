# arXiv upload instructions

This folder is the clean source package for:

**Tiny: Verified Skill Migration for Reducing LLM Fallbacks in Neuro-Symbolic Question Answering**  
**Author:** Alexander Revyakin

Suggested primary category: `cs.AI`  
Possible cross-lists: `cs.CL`, `cs.LG`

## Files to upload

- `main.tex`
- `main.bbl`
- `references.bib`

The package contains no experiment traces, Git history, reviewer notes, credentials, absolute Windows paths, or unrelated build artifacts.

## Manual submission steps

1. Sign in to the author's personal account at the official arXiv site and complete any required email or author verification.
2. Start a new submission and upload the prepared ZIP containing the three files above at its root.
3. Select `main.tex` as the primary TeX file if arXiv does not detect it automatically.
4. Use `cs.AI` as the primary category. Add `cs.CL` and/or `cs.LG` only if the author considers the cross-list appropriate and the interface permits it.
5. Copy the final abstract from `../notes/SUBMISSION_METADATA.md`; do not rewrite the scientific content during upload.
6. Confirm the title and author exactly as shown above.
7. Inspect arXiv's compiled PDF and metadata preview carefully before submission.
8. If endorsement, CAPTCHA, moderation, or another account-holder action is required, complete it through arXiv's normal process; do not attempt to bypass it.

After arXiv issues an identifier, update the repository README, `CITATION.cff`, project page, repository metadata, and release notes with the real URL. Do not invent an arXiv identifier.
